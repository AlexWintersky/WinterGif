WINTERGIF 1.2 - PORTABLE WINDOWS EDITION
=======================================

ENGLISH
-------
1. Extract the entire WinterGif-Release folder from the ZIP.
2. Double-click WinterGif.exe.
3. Choose Capture region, drag a rectangle, and press F8 to stop.
4. Preview, trim, delete frames, crop, and export a GIF.

No Python installation, online account, or internet connection is required.
Keep the _internal folder next to WinterGif.exe: it contains app dependencies.
Windows 10/11 (64-bit) recommended. GIF does not support audio.

PORTUGUES
---------
1. Extraia a pasta WinterGif-Release inteira do ZIP.
2. De dois cliques em WinterGif.exe.
3. Use Capturar area, selecione a regiao e pressione F8 para parar.
4. Visualize, corte ou exclua quadros e exporte seu GIF.

Nao precisa instalar Python, abrir terminal, ou usar internet.
Mantenha a pasta _internal junto de WinterGif.exe: ela e necessaria.
Recomendado para Windows 10/11 de 64 bits. GIF nao tem audio.

SECURITY
--------
This EXE is not digitally signed. Windows may warn about unknown publishers.
Only download from the author's official GitHub repository, inspect the source
if desired, and never disable antivirus protections to run unknown software.
